# Tutor Booking Platform

## 🌐 Live Site

https://tutor-booking-alpha.vercel.app

---

##About This Project

Tutor Booking Platform একটি web application যেখানে students সহজে tutor খুঁজে বের করতে পারে এবং online session booking করতে পারে।

---

## Features

- Online tutoring session booking system
- Secure login / registration system
- Tutor profile management system
- Fully responsive design (mobile + desktop friendly)
- Fast and smooth user experience

---

## Technologies Used

- Next.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- JWT Authentication
